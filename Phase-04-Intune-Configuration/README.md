# Phase 4 - Intune Configuration

## Objective

Configure Microsoft Intune to provide centralised endpoint management for enrolled devices.

## Actions Completed

During this phase, Microsoft Intune was configured to manage and secure enrolled Windows devices.

The following configurations were implemented:

- Device Compliance Policies
- Configuration Profiles
- Windows Update Rings
- Application Deployment
- Endpoint Security Settings

## Compliance Policies

Compliance policies were configured to ensure devices met organisational security requirements before gaining access to company resources.
