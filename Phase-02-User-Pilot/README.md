# Phase 2 - User Pilot

## Objective

Validate user synchronisation and prepare users for Intune enrolment.

## Actions Completed

- Created a dedicated pilot OU in Active Directory
- Allowed the OU to synchronise through Microsoft Entra Connect
- Confirmed pilot users appeared in Microsoft Entra ID
- Verified users were shown as synchronised from on-premises Active Directory
- Added pilot users to the Intune Users Pilot security group
- Confirmed automatic enrolment processes were functioning correctly

## Outcome

Pilot users successfully synchronised to Microsoft Entra ID and became eligible for Microsoft Intune enrolment.
