A pilot-first deployment methodology was adopted.

A Microsoft 365 security group named: 

Intune Users Pilot

was created and used to control access to cloud management services.

The pilot initially consisted of a single test account for:

- Authentication testing
- Synchronisation validation
- Password change verification
- Licensing verification

Following successful testing, additional users were gradually added.

# Objective
The objective of this phase was to validate synchronised user accounts before wider deployment.

# Actions Completed 
- Created pilot security group
- Added test account
- Assigned licensing
- Validated password synchronisation
- Tested Microsoft 365 access
- Monitored synchronisation health

# Outcome
The pilot user successfully authenticated using synchronised credentials and was prepared for Intune onboarding.
