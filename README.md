# Hybrid Identity and Intune Deployment

This repository documents a Microsoft Entra ID and Intune deployment carried out within a production environment.

The project included:

- Active Directory identity preparation
- UPN suffix management
- Attribute cleanup
- Microsoft Entra Connect deployment
- Password Hash Synchronisation
- User synchronisation
- Intune pilot group creation
- Device enrolment
- Intune policy deployment
- Security hardening
- Production rollout

The project was completed gradually using pilot users and pilot devices to minimise risk.
