# Lessons Learned

## Pilot First

Using a dedicated test account allowed synchronisation issues to be identified before wider deployment.

## OU Filtering

Scoping synchronisation to test OUs reduced risk and provided greater control during implementation.

## Security Group Targeting

Using dedicated Microsoft 365 security groups allowed staged user onboarding and simplified management.

## Monitoring

Microsoft Entra Connect synchronisation logs were reviewed regularly throughout implementation to ensure successful user and device synchronisation.
